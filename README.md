# EliteHomes - Your Dream Home Awaits

A real estate landing site for a property agency: services, property types, featured listings, popular locations, client testimonials, FAQ and contact.

**Live demo:** https://yosef-tamer206.github.io/EliteHomes---Your-Dream-Home-Awaits/

## Features

- Hero section with property search banner
- Services overview (buying, selling, rentals, investment)
- Property types and featured properties galleries
- Popular locations section
- Client testimonials
- Frequently asked questions
- Contact section with agency details
- Responsive layout with dedicated media-query stylesheet

## Tech Stack

- HTML5
- CSS3 (custom styles plus a separate responsive `media.css`)
- Bootstrap 5
- Font Awesome icons

## Run Locally

```bash
git clone https://github.com/Yosef-Tamer206/EliteHomes---Your-Dream-Home-Awaits.git
cd EliteHomes---Your-Dream-Home-Awaits
```

Open `index.html` in a browser.

## Notes

- Front-end only. Listings, prices, testimonials and contact details are sample content for the design.
